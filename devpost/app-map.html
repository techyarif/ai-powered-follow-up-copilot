AI Real Estate Follow-Up Co-Pilot

This local dashboard turns a call recording into an editable lead, a future follow-up, and a WhatsApp draft. Leads and their edits stay in this browser; reminders only run while the dashboard is open.

Reference route through the code

Use this route when you want to trace the audio result. It is a reference map, not a claim that you have toured these files.

  1. web/app/api/analyze/route.ts — start at POST. It validates the uploaded file, sends its bytes to Gemini in one request, then parses and validates the returned JSON.
  2. web/lib/lead-schema.ts — follow parseAnalysisResult. This is the shared contract check that rejects incomplete or incorrectly shaped model output.
  3. web/app/page.tsx — follow analyzeAudio for the response-to-lead conversion; then checkDueReminders inside the reminder effect and playReminderChime for the due alert and sound.

A practice to reuse

The requested Gemini model failed against the configured key with a real 404. The model was changed only after the learner agreed, and a real audio request then verified the alternative. On another AI integration, check the provider's actual response with representative input, preserve the product behavior, and validate the returned shape before building more UI around it.

Run it again

From web/, run npm run dev and open http://localhost:3000. The server needs the local GEMINI_API_KEY in web/.env.local to analyze audio. Keep that file private.

Source snapshot: commit c7bbfe9 (Add confirmed lead deletion). This guide describes that source snapshot and can drift as the code changes.

Where does audio and lead data go?

The browser sends uploaded audio to the local API route for transient Gemini analysis. The app stores the resulting transcript and editable lead card in this browser's localStorage, not the raw audio. This is browser-local storage, not cross-device sync.

Keep the app open for reminders. Browser notifications and sound require permission or user activation and can be restricted by browser settings.
